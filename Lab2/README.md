В этом файле нужно описать порядок выполнения и запуска своей лабы.

## Сборка и запуск
| Инструмент | Имя |
|------------|-----|
| компилятор RISC-V | `riscv64-unknown-elf-gcc` |
| виртуальная машина | `qemu-system-riscv64` |
Сборка и запуск проводились на Ubuntu v24.04, в других дистрибутивах возможны другие имена инструментов, их можно поменять в Makefile.


## Системные вызовы
| Имя | Описание | Аргументы | Реализовано |
|-----|----------|-----------|-------------|
| `syscall_timer_init` | Включение прерываний по таймеру | нет аргументов | YES |
| `syscall_timer_set` | Изменение mtimecmp | `a0`: inc (настройка прерывания таймера для срабатывания через inc тактов, если аргумент равен 0, то выставляется максимальное беззнаковое 64-битное число) | YES |
| `syscall_uart_print` | Запись в uart | `a0`: указатель на строку | Yes |
